# Image provenance

The images in this directory are original visual assets created for the Flaq.ai open-source repository. They are included to make the project easier to browse and to illustrate the kinds of deliverables covered by the prompt library.

They are **not presented as official Google assets or Nano Banana Pro benchmark outputs**. The repository did not have a Gemini API credential during this build, so the initial project illustrations were created with a separate image-generation tool and are clearly treated as editorial references. Contributors may replace or extend `assets/examples/` with genuine Nano Banana Pro results when they:

1. generated the image from an original prompt in this repository;
2. have the right to publish every input and output;
3. record the model ID, prompt file, date, aspect ratio, and any edits;
4. preserve SynthID and comply with the service terms;
5. do not describe a cherry-picked example as a controlled benchmark.

Suggested sidecar metadata:

```yaml
title: Multilingual cafe menu
model: gemini-3-pro-image
prompt_file: prompts/08-editing-and-localization.md
recipe: Localized menu without layout drift
generated_at: 2026-08-28
aspect_ratio: 4:5
inputs: rights-cleared original assets
post_processing: crop only
```
