## このリポジトリについて

ブランド広告、EC、SNS、インフォグラフィック、UI、キャラクター、写真、建築、ファッション、旅行、動植物、文字組み、ゲーム、歴史文化、出版、画像編集、ローカライズ、ビジネス資料を対象に、**20カテゴリー・100本のオリジナルレシピ**を収録しています。

各レシピは、用途、構図、参照画像の役割、画像内の正確な文言、変更してはいけない要素、最終確認までを一つの制作仕様として記述します。第三者のプロンプトを転載したコレクションではありません。

## 使い方

1. [プロンプト一覧](prompts/)から目的に近いレシピを選びます。
2. `{{変数}}` を自分の要件に置き換えます。
3. 指定された順番で参照画像を追加します。
4. Gemini、Google AI Studio、または Gemini API で生成します。
5. 文字、数値、人物、商品形状、事実、トリミングを確認します。
6. 修正は一度に一項目とし、固定条件を毎回繰り返します。

日本語の画像内テキストでは、承認済み文言をそのまま提示し、句読点、小書き仮名、長音、全角・半角、数字と単位の分離、自然な改行を確認してください。
