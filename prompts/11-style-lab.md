# Style Lab Prompts

These recipes describe visual properties instead of asking to copy a named living artist.

## 1. Isometric city vignette

**Best for:** explainers and destination concepts · **Format:** 1:1 · **Difficulty:** Intermediate

```text
Create a clean 45-degree isometric vignette of {{place_or_system}} showing {{key_elements}}. Use believable scale,
consistent orthographic-like projection, soft PBR materials, gentle ambient occlusion, and one clear focal point.
Background: {{simple_background}}; palette: {{palette}}; atmosphere: {{weather_or_time}}.

No miniature tilt-shift blur, mixed vanishing points, floating buildings, copied landmarks beyond factual depiction,
text, logos, or unnecessary border. Keep all shadows consistent with one light source.
```

## 2. Tactile clay illustration

**Best for:** friendly education and onboarding · **Format:** 4:5 · **Difficulty:** Beginner

```text
Create a tactile clay illustration of {{subject_and_action}}. Forms are hand-shaped with subtle fingerprints, rounded
edges, matte clay roughness, simple expressive faces, and a physical tabletop set. Use {{palette}} and soft large-source
studio light. Composition: {{composition}}.

No glossy plastic, floating parts, hyper-detailed skin, text, logos, or extra characters. Preserve simple readable
silhouettes and physically plausible contact between every object.
```

## 3. Contemporary watercolor field note

**Best for:** nature, food, and travel illustration · **Format:** 3:2 · **Difficulty:** Intermediate

```text
Create an original watercolor-and-ink field-note illustration of {{subject}} on warm cotton paper. Use transparent
layered washes, restrained ink contours, pigment blooms, dry-brush texture, and incomplete edges. Arrange one main
study with {{detail_count}} smaller detail studies and the supplied factual labels: {{labels}}.

No imitation of a named artist, copied plate layout, false scientific detail, decorative cursive text, or watermark.
Keep labels legible and leader lines accurate.
```

## 4. Layered paper-cut scene

**Best for:** campaigns and children's visuals · **Format:** 16:9 · **Difficulty:** Intermediate

```text
Create a handcrafted layered paper-cut scene of {{scene}} using 7–9 visible paper depth planes. Show fibrous cut edges,
subtle bends, real cast shadows between layers, restrained {{palette}}, and a clear foreground-to-background rhythm.
Light from {{direction}}. Leave {{negative_space_location}} open for later layout.

No text, logos, plastic surfaces, impossible thin unsupported pieces, or flat vector appearance. Keep every element
constructible from cut paper.
```

## 5. Pixel-art game environment

**Best for:** game concept and retro campaigns · **Format:** 16:9 · **Difficulty:** Advanced

```text
Create an original 16:9 pixel-art environment of {{location}} at {{time}}. Use a deliberate {{approx_palette_size}}-color
palette, crisp nearest-neighbor pixels, coherent tile scale, readable depth planes, and one gameplay focal area.
Include {{required_objects}} with consistent sprite scale.

No mixed pixel densities, anti-aliased edges, painted gradients, existing game IP, logos, text, or impossible perspective.
Keep silhouettes readable at 50% size and preserve a tileable logic where surfaces repeat.
```
