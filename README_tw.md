## 專案內容

本專案收錄 **11 個分類、55 組原創提示詞配方**，涵蓋品牌廣告、電商商品圖、社群內容、資訊圖表、UI、角色設定、分鏡、攝影、精準編修、在地化、商業簡報與在地商家行銷。

每組配方都會描述成果用途、構圖、參考圖片角色、必須逐字呈現的文案、不可改動項目及輸出前檢查。本專案不收錄刪除作者資訊或僅做輕微改寫的第三方提示詞。

## 快速使用

1. 從[提示詞目錄](prompts/)選擇最接近的成果類型。
2. 替換所有 `{{變數}}`。
3. 依照指定順序加入參考圖片。
4. 在 Gemini、Google AI Studio 或 Gemini API 生成。
5. 檢查文字、數字、人物、商品結構、事實和裁切。
6. 每次只修正一類問題，並重複所有鎖定條件。

繁體中文內容請指定 `zh-TW` 或實際目標地區，鎖定品牌名、價格、SKU 和法律文字，並檢查字形、標點、全形半形與自然斷行。
