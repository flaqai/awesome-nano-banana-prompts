## สิ่งที่มีในโครงการ

คลังนี้มี **พรอมป์ต้นฉบับ 100 สูตรใน 20 หมวดหมู่** ครอบคลุมโฆษณา อีคอมเมิร์ซ โซเชียลมีเดีย อินโฟกราฟิก UI ตัวละคร ภาพถ่าย สถาปัตยกรรม แฟชั่น การท่องเที่ยว สัตว์และพฤกษศาสตร์ ตัวอักษร เกม ประวัติศาสตร์ สิ่งพิมพ์ การแก้ไขแบบควบคุม และการแปลเป็นภาษาท้องถิ่น

แต่ละสูตรระบุเป้าหมาย องค์ประกอบ บทบาทของภาพอ้างอิง ข้อความที่ต้องแสดงตรงตัว สิ่งที่ห้ามเปลี่ยน และขั้นตอนตรวจสอบขั้นสุดท้าย ไม่ใช่การรวบรวมพรอมป์ของผู้อื่นโดยลบที่มา

## เริ่มใช้งานอย่างรวดเร็ว

1. เลือกสูตรตามชนิดผลงานที่ต้องการ
2. แทนที่ `{{ตัวแปร}}` ทุกจุด
3. แนบภาพอ้างอิงตามลำดับที่ระบุ
4. สร้างใน Gemini, Google AI Studio หรือ Gemini API
5. ตรวจข้อความ ตัวเลข บุคคล รูปทรงสินค้า ข้อเท็จจริง และการครอป
6. แก้ปัญหาทีละประเภทและย้ำข้อจำกัดทุกครั้ง

สำหรับข้อความภาษาไทย ให้ระบุกลุ่มเป้าหมาย ปกป้องชื่อแบรนด์ ราคา และรหัสสินค้า พร้อมตรวจวรรณยุกต์ สระ ตำแหน่งเครื่องหมายวรรคตอน ตัวเลข และการตัดบรรทัดกับเจ้าของภาษา
